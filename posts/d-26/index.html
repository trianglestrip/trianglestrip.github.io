钻石戒指 3D 查看器，基于 WebGI 渲染管线（本地资源、零外部网络）。本文解析其渲染管线、钻石材质、后处理各模块与交互机制。

在线演示

https://trianglestrip.github.io/demo/Diamond3d/app/

架构总览

flowchart LR A["模型加载<br/>AssetManager (GLTF)"] --> B["材质解析<br/>DiamondMaterial / 扩展"] B --> C["GBuffer<br/>深度/法线/标志"] B --> D["PMREM 环境贴图"] D --> E["光照<br/>RandomizedDirectionalLight"] C --> F["SSR 反射 / SSAO 遮蔽"] E --> G["RenderPass2<br/>主渲染 Pass"] F --> G G --> H["Progressive / TAA<br/>时域累积"] H --> I["Bloom 泛光"] I --> J["CombinedPost<br/>合成 + 色调映射"] J --> K["屏幕输出"]

渲染管线

GBuffer -> SSR / SSAO -> RenderPass2 -> Progressive(TAA) -> Bloom -> CombinedPost -> Screen

WebGI 采用分阶段渲染：BaseRenderer 通过 EffectComposer 串联多个 pass，每次 WebGL 渲染由 renderer.userData 标志门控（setThreeRendererMode），避免几何被多画。

1. GBuffer

  • 渲染不透明几何的深度、法线、材质标志（curvature / flags）
  • 门控：opaqueRender: true，其余 pass 关闭
  • 产出 G-Buffer 供 SSR/SSAO/RenderPass2 使用

2. SSR / SSAO

  • SSR（屏幕空间反射）：GBuffer 法线 + 深度 → 射线步进，命中点取 tLastFrame 颜色，带 roughness 模糊
  • SSAO（环境遮蔽）：采样深度/法线 → 曲率权重，产出 AO 贴图

3. RenderPass2（主渲染）

flowchart LR P["RenderPass2"] --> A["Pass A<br/>shadowMapRender / backgroundRender / opaqueRender<br/>阴影 + 背景 + 不透明"] P --> B["Pass B<br/>transparentRender<br/>透明对象"] P --> C["Pass C<br/>transmissionRender<br/>透射对象 (transmissionRenderTarget)"]
PassuserData 标志内容
AshadowMapRender backgroundRender opaqueRender阴影贴图 + 背景（走 tonemapping 管线）+ 不透明几何
BtransparentRender透明对象
CtransmissionRender透射对象，采样 transmissionRenderTarget（当前帧已渲染画面）做折射背景

4. Progressive / TAA

  • 渐进式采样累积（jitter 偏移），tLastFrame 反馈混合，收敛后静止画面抗锯齿

5. Bloom / CombinedPost

  • Bloom：提取 HDR 高亮 → 多级高斯模糊 → 加权叠加（intensity / weight 可调）
  • CombinedPost：合成各 buffer + 色调映射（ACES/NoTonemap 等）+ 颜色编码

钻石材质（DiamondMaterial）

  • 66 个钻石 mesh 解析为 DiamondMaterial（ShaderMaterial 扩展）
  • 光线追踪近似：入射 → 折射 → 内全反射 → 出射，含色散（不同波长折射率差）

核心参数（点击钻石后 Material Configurator 可调）

参数作用
color钻石基色（吸收色）
envMapIntensity环境贴图反射强度
transmission透射率（折射背景采样）
ior折射率（1.0-3.0）
thickness透射厚度（Beer 定律衰减）
gammaFactor色散系数（色散强度）
boostFactors内反射/火彩增强
absorptionFactor光吸收（颜色饱和度）
rIndexDelta折射率差（虹彩）
reflectivity反射率
opacity / transparent透明度控制

透射渲染流程

flowchart TD A["RenderPass2 PassA 不透明阶段<br/>钻石主体写入 GBuffer 深度/法线"] --> B["PassC 透射阶段<br/>用 transmissionRenderTarget(当前帧画面)"] B --> C["折射背景采样<br/>transmission * refraction"] C --> D["内反射 + 色散<br/>gammaFactor / boostFactors"] D --> E["环境贴图反射<br/>envMapIntensity + PMREM"] E --> F["TAA 累积 + Bloom + 合成输出"]

three.js 运行时（相对 npm r160）

  • 渲染器 userData 多 pass 门控（opaqueRender/transparentRender/transmissionRender/sceneRender/backgroundRender/shadowMapRender）
  • extraUniformsToUpload：按 draw 上传材质扩展 uniform（材质扩展注入）
  • rgbm-16 颜色空间编解码（HDR 中间结果）
  • 背景颜色走渲染管线（tonemapping/编码）

交互

  • 点击 mesh：PickingPlugin 拾取 → selectedObjectChanged → 右侧 Configuration 面板顶部挂载该 mesh 的 Physical Material 参数，实时可调；其他面板折叠状态保持
  • UI 面板：Renderer / Hierarchy / Material Configurator / Camera Views / Ground，左上角「UI 开关」一键显隐
  • 后处理：Renderer 面板实时调节（Mode / Width / Height / Scale / Bloom / exposure）
